# Studi Kasus 1 — Analisis Nilai Mahasiswa

## Masalah
Mengolah nilai mahasiswa secara ringkas, menghitung nilai akhir, mencari mahasiswa dengan nilai di atas 80, membuat ranking, dan menampilkan mahasiswa terbaik.

## Konsep Python
- **List comprehension** untuk membuat data nilai akhir dan menyaring mahasiswa berprestasi.
- **Lambda function** sebagai kunci pengurutan berdasarkan nilai akhir.
- **Filtering dan sorting** melalui list comprehension dan `sorted()`.

## Rumus Nilai Akhir
`Nilai akhir = (Tugas × 30%) + (UTS × 30%) + (UAS × 40%)`.

## Cara Menjalankan
```bash
python main.py
```
